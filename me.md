### 👨‍💻 About Me

I am a versatile **Full-Stack Software Engineer & Technical Consultant** with proven experience delivering robust digital solutions across **Mobile (Android & Flutter), Modern Web (Laravel & Vue.js), High-Performance Backends (Go & PHP), and Cloud/VPS Infrastructure**.

With a strong foundation in native Android (Java & Kotlin) and full-stack web architecture, I help startups, businesses, schools, and organizations turn complex requirements into high-value, production-grade applications — from initial database modeling to live server and domain deployment.

**Core Expertise:**
- 📱 **Mobile Development:** High-performance, reactive Android apps using **Kotlin/Java** and multi-platform solutions with **Flutter (Dart)** for Android, iOS, and Windows Desktop.
- 💻 **Modern Web Ecosystem:** Dynamic, responsive single-page applications (SPA) and admin control portals with **Vue.js**, paired with elegant, scalable backend architectures built on **Laravel (PHP)**.
- ⚙️ **High-Performance Backends:** Microservices, background workers, and low-latency RESTful APIs using **Go (Golang)** and **Laravel**.
- 🗄️ **Databases & Cloud Sync:** Enterprise relational schema design in **MySQL**, lightweight local caching with **SQLite (WAL mode)**, and real-time reactive sync using **Firebase Firestore**.
- 🌐 **DevOps, VPS & Hosting:** Complete server lifecycle setup — provisioning Linux VPS (Ubuntu/Debian), Nginx reverse proxy, SSL/HTTPS (Let's Encrypt), DNS & domain routing, firewall hardening, and daemon process management (systemd).
- 🔌 **Hardware & Local Automation:** IoT device communication, USB relay control, offline-first LAN synchronization, and automated Text-to-Speech (TTS) integration.
